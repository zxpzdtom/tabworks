本地 bridge 接口总览

除 GET /status 外，接口需要本地服务在线、扩展已连接，并携带 X-TabWorks-Bridge: 1 请求头。

能力 方法 接口 用途 操作
SYS 服务状态
GET /status 检查本地服务和扩展连接状态。
NAV 页面导航
POST /open 创建自动化窗口、打开 URL、跳转、选择或关闭标签页。
DOM 读取 DOM
POST /inspect 读取页面标题、文本和链接摘要。
JS 执行脚本
POST /run-js 在目标页面上下文运行 JavaScript，读取 DOM 或调用页面函数。
TAP 点击元素
POST /tap 点击指定 selector；mode: "mouse" 会走 CDP 鼠标事件，适合 antd Select。
PRS 长按元素
POST /press 按住 selector 或坐标一段时间后释放，用于录制脚本里的长按手势。
DRG 拖拽元素
POST /drag 从 selector 或坐标开始拖到指定位置，也支持 deltaX/deltaY。
KEY 键盘按键
POST /key 发送可信键盘事件；录制脚本会用它稳定回放 dnd-kit 排序。
INP 输入文本
POST /input 兼容 input、textarea、select 和 contenteditable；受控组件会触发 input/change。
API 请求接口
POST /request 在页面上下文发起 fetch，例如请求 /api/animals 并携带当前登录态。
IMG 页面截图
POST /capture 截取当前视口或整页截图，可返回图片内容或保存到文件。
CK 读取 Cookie
POST /cookies 按 URL 或域名读取 cookie。
RUN 会话状态
POST /sessions 查看自动化窗口和标签页状态。

浏览器扩展无法直接判断系统里是否安装了 CLI，只能检测 localhost:9527 的 bridge/log 服务是否在线。

权限对应能力

权限只解释扩展能做什么，不代表 CLI 已安装。

debugger / tabs CDP 命令、自动化窗口、导航、截图。
cookies 读取用户指定范围内的登录态 cookie。
storage / alarms 保存 popup 设置并维持 MV3 后台连接。
